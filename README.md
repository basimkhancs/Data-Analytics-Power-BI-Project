# Data-Analytics-Power-BI-Project
Power BI project analyzing public-sector workforce classification data to measure service standard compliance, using DAX and Power Query with interactive dashboards.

# Workforce Service Standards Analysis (Power BI)

This project analyzes workforce classification request data to evaluate service standard compliance within a public-sector context.

Using Power BI, the project calculates how long each request took to complete (excluding weekends) and determines whether it met predefined service standard deadlines based on request type. The analysis produces counts and compliance percentages and presents results through interactive dashboards.

## Key Features
- Data cleaning, validation, and transformation using Power Query
- Service standard compliance calculations using DAX
- Working-day time calculations (excluding weekends)
- Interactive dashboards with drill-downs by Ministry and Bargaining Unit
- Clear visual reporting to support operational and data-driven decision-making

## Tools Used
- Power BI Desktop
- DAX
- Power Query
- Excel (data source)

## Purpose
This project was completed as part of an academic and co-op-style assignment to demonstrate data analysis, reporting, and visualization skills in a public-sector analytics setting.
